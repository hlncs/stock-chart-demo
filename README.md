## Overview

A full-stack stock chart demo with:

- **Backend** — FastAPI + Pandas, serving price history and AI-driven analysis
- **Frontend** — React + TypeScript, Vite, Material UI (dark mode), Recharts

Key features:
- Interactive price chart with overlay SMAs (20, 50, custom window)
- Hover tooltip showing date, price, active SMAs, and trade volume
- AI buy/hold/sell analysis pane powered by an LLM
- Portfolio tracker — transactions ledger with BUY/SELL entries, P&L, market value
- Ticker list management — add new symbols (downloads via yfinance) or remove existing ones

## Setup

### Prerequisites

- Python 3.12+
- Node.js 18+
- Internet access (yfinance downloads from Yahoo Finance)

### 1 — Create the Python virtual environment

```bash
cd stock-chart-demo
python3 -m venv .VENV
source .VENV/bin/activate        # Windows: .VENV\Scripts\activate
pip install -r backend/requirements.txt
```

### 2 — Start the backend

```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

The API is now available at `http://localhost:8000`.
Interactive docs: `http://localhost:8000/docs`

### 3 — Start the frontend

```bash
cd frontend
npm install
npm run dev
```

The app opens at `http://localhost:5173`.

## Loading Test Data

The backend reads price history from Parquet files in `backend/data/`.
You need to populate this directory before the app will display any charts.

### Step 1 — Download price history

Use `load_data.py` to pull daily OHLCV data from Yahoo Finance and save it as
Parquet files. Run this from the `backend/` directory with the virtual
environment active.

**Initial load (full history):**

```bash
cd backend
python load_data.py --initial --symbols AAPL MSFT NVDA AMZN V --period 5y
```

**Append only new dates (incremental update):**

```bash
python load_data.py --append --symbols AAPL MSFT NVDA AMZN V
```

**Load a single symbol:**

```bash
python load_data.py --initial --symbols TSLA --period 3y
```

**CLI options:**

| Flag | Description | Default |
|------|-------------|---------|
| `--initial` | Download full history, overwrite existing | true if `--append` not set |
| `--append`  | Download only dates newer than what is stored | — |
| `--symbols` | One or more ticker symbols | `MSFT NVDA AMZN AAPL` |
| `--period`  | yfinance period: `max`, `5y`, `3y`, `2y`, `1y` | `max` |

Expected output:

```
2026-08-05 17:04:52 INFO load_data Loading AAPL
2026-08-05 17:04:52 INFO load_data Loading MSFT
...
2026-08-05 17:04:53 INFO load_data Saved 1254 rows for AAPL
2026-08-05 17:04:53 INFO load_data Saved 1254 rows for MSFT
...
```

Resulting files:

```
backend/data/
├── AAPL.parquet
├── AMZN.parquet
├── MSFT.parquet
├── NVDA.parquet
└── V.parquet
```

### Step 3 — Adding symbols via the UI

New symbols can be added without using the CLI. In the app:

1. Click **Add Symbol** at the bottom of the Ticker List
2. Enter a ticker (e.g. `TSLA`)
3. Choose how much history to load (Max / 5y / 3y / 2y / 1y)
4. Click **Add** — price data is downloaded and the chart is ready immediately

To remove a symbol, hover over its row in the Ticker List and click the delete
icon. Portfolio transactions for that symbol are preserved.

## API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET    | `/symbols` | List all available ticker symbols |
| POST   | `/symbols` | Add a symbol (downloads via yfinance) |
| DELETE | `/symbols/{symbol}` | Remove a symbol |
| GET    | `/prices/{symbol}?period=` | OHLCV price history |
| GET    | `/moving-average/{symbol}?period=&window=` | SMA values |
| GET    | `/indicators/{symbol}?period=&rsi_period=&macd_fast=&macd_slow=&macd_signal=` | RSI + MACD |
| GET    | `/ai-analysis/{symbol}?period=&custom_window=` | AI buy/hold/sell analysis |
| GET    | `/portfolio` | Portfolio summary (derived from transactions) |
| GET    | `/portfolio/transactions/{symbol}` | Transaction history for a symbol |
| POST   | `/portfolio/transactions` | Add a BUY or SELL transaction |

Full interactive docs at `http://localhost:8000/docs` when the backend is running.

## Architecture

```
Browser
  └── React SPA (Vite, port 5173)
        └── Axios  ──/api/──►  FastAPI (uvicorn, port 8000)
                                  ├── StockRepository  ──►  *.parquet  (data/)
                                  ├── StockService
                                  ├── MovingAverageService
                                  └── AIAnalysisService  ──►  LLM + documents/
```

- All price data is stored locally as Parquet files — no live market feed is
  required after the initial load.
- Portfolio state is persisted in `transactions.parquet`; holdings and P&L are
  computed on every request by replaying the ledger.
- The Vite dev server proxies `/api` requests to `localhost:8000` (see
  `frontend/vite.config.ts`).
